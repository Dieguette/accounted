Feature:
Copy customer email

User problem:
Users need to copy an email address without selecting the text manually.

Expected behavior:
A copy button appears beside an existing customer email.
Clicking it copies the address and shows confirmation.
If no email exists, no copy action is available.
If copying fails, show an error.

Not included:
Changing customer data, sending emails, or changing permissions.

Acceptance checks:
The copied text matches the displayed email.
Success feedback appears.
Missing emails are handled.
Copy failures are handled.
